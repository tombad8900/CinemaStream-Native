# الأمان والخصوصية

## 1. مبادئ عامة
- جمع أقل قدر لازم من البيانات.
- عدم إرسال بيانات التشخيص أو المكتبة إلى أي جهة دون سبب واضح وموافقة مناسبة.
- فصل بيانات المتصفح عن بيانات المكتبة.
- عدم تسجيل الأسرار أو روابط التشغيل التي تحتوي على Tokens.
- إظهار الصلاحيات وسبب طلبها للمستخدم.

## 2. المستودع العام والأسرار
المستودع Public، لذلك:
- ممنوع رفع TMDB API key أو كلمات مرور أو Access Tokens أو مفاتيح توقيع أو ملفات keystore.
- استخدام ملف محلي غير متعقب أو متغير بيئة عند الحاجة أثناء البناء.
- إضافة ملفات الأسرار إلى .gitignore قبل إدخال أي قيمة.
- إذا تسرب سر إلى Git، لا يكفي حذف الملف؛ يجب إبطال السر وتدويره.
- لا تضع أسرارًا في Issues أو سجلات CI أو لقطات الشاشة.

## 3. مفاتيح API
أي مفتاح داخل APK يمكن استخراجه من التطبيق. لذلك لا نصف مفتاح العميل بأنه سري لمجرد وضعه في BuildConfig أو تشفيره داخل الكود. نراجع شروط مزود الخدمة وخيارات تقييد المفتاح، ونخزن بيانات المستخدم أو مفاتيحه الشخصية محليًا بأقل صلاحيات ممكنة، ولا نرسل مفاتيح أو Tokens إلى محرك التشخيص.

## 4. المتصفح والجلسات
- الجلسات العادية منفصلة عن الجلسات الخاصة.
- الجلسة الخاصة لا تستخدم ملفات تعريف ارتباط أو Cache دائمًا مشتركًا مع العادية.
- عند إنهاء الجلسة الخاصة، يتم إنهاء مواردها ومسح بياناتها وفق قدرات GeckoView الموثقة.
- لا يتم تصدير Cookies أو كلمات المرور أو سجل التصفح ضمن نسخة المكتبة.
- لا تُعرض محتويات الصفحات على أنها موثوقة لمجرد ظهورها داخل التطبيق.

## 5. اكتشاف البث
- التعامل مع URI وHeaders باعتبارها بيانات غير موثوقة.
- لا نتبع Redirects أو نمرر Headers حساسة إلى نطاقات غير موثوقة دون تحقق.
- تقييد أنواع ومصادر الطلبات التي يمكن تحليلها.
- لا تجاوز DRM أو CAPTCHA أو المصادقة أو القيود التقنية.
- عدم حفظ Tokens قصيرة العمر في سجل المشاهدة أو ملفات التصدير.
- عند عرض رابط للمستخدم، يمكن تنقيح Query parameters الحساسة من السجلات.

## 6. التنزيلات والترجمات
- التحقق من حجم الملف ونوعه الفعلي قبل فك الضغط أو استخدامه.
- وضع حدود لعدد الملفات والحجم الإجمالي وعمق المجلدات.
- منع Zip Slip والمسارات المطلقة وروابط الملفات غير المسموحة.
- حفظ الملفات داخل مساحة التطبيق الخاصة.
- رفض الملفات التنفيذية أو غير المتوقعة في مسار الترجمة.
- عدم فتح ملفات نزلت من مصدر غير موثوق تلقائيًا.

## 7. IPTV وملفات M3U/XMLTV
- اعتبار كل ملف أو رابط قائمة إدخالًا غير موثوق.
- تحديد حدود لحجم القائمة وعدد العناصر وطول السطر.
- التحقق من الروابط وأنواع البروتوكولات.
- عدم تنفيذ أوامر أو تحميل ملفات محلية استنادًا إلى محتوى القائمة.
- عدم السماح للقائمة بتجاوز سياسات الشبكة أو الخصوصية.

## 8. السجلات والتشخيص
- تسجيل رمز الخطأ ونوع المصدر والمرحلة بدل تسجيل الرابط الكامل عند احتوائه على بيانات اعتماد.
- تنقيح Authorization وCookie وSet-Cookie وTokens.
- التشخيص يعمل بطلب المستخدم فقط.
- عرض البيانات التي ستتم مشاركتها قبل أي إرسال خارجي.
- عدم رفع الفيديو أو الصوت أو ملفات الترجمة الخاصة تلقائيًا.

## 9. أذونات Android
نطلب أقل مجموعة أذونات لازمة. لا نطلب الوصول الشامل للملفات إذا أمكن استخدام Storage Access Framework. تراجع كل صلاحية مع الميزة التي تحتاجها، ويجب أن يكون رفض الصلاحية غير الضرورية لا يعطل التطبيق كله.

## 10. التحديثات والاستجابة للحوادث
- تحديث الاعتماديات عند وجود إصلاح أمني أو توافق مهم.
- توثيق مصدر كل مكتبة وترخيصها.
- إزالة أو استبدال مكتبة غير صيانة أو عالية المخاطر.
- عند اكتشاف تسريب أو ثغرة، نحدد الأثر ونبطل الأسرار المتأثرة ونوثق المعالجة.
