# CinemaStream Native

إعادة بناء تطبيق CinemaStream كتطبيق Android أصلي مستقل، مع الاستفادة من أفكار وتجارب المشروع السابق دون نسخ بنيته أو تعديل مستودعه.

> **الحالة الحالية:** التنفيذ بدأ. التطبيق يُبنى ويعمل (debug) والمتصفح الداخلي مع حظر الإعلانات والأيقونة جاهزين. التفاصيل في [PROGRESS.md](PROGRESS.md).

## الرؤية
تطبيق سينمائي عربي بواجهة حديثة داكنة، يجمع مكتبة الأفلام والمسلسلات والأنمي، المشغل الأصلي، المتصفح الداخلي، اكتشاف مصادر البث، الترجمات، وميزات IPTV في تطبيق واحد ذي وحدات مستقلة.

## المبادئ الأساسية
- Android أصلي؛ لا نعتمد على HTML أو WebView كواجهة التطبيق.
- Kotlin وJetpack Compose للواجهة، وAndroidX Media3 للتشغيل، وRoom للبيانات المحلية.
- فصل المحركات والميزات لتسهيل التطوير والاستبدال والاختبار.
- التشغيل داخل الموقع يظل خيارًا احتياطيًا عندما لا يتوفر مصدر مباشر صالح.
- لا تجاوز لـDRM أو CAPTCHA أو ضوابط الوصول أو حماية المواقع.
- لا تُضمّن مفاتيح API أو كلمات المرور أو الرموز السرية في المستودع العام.
- بيئة التطوير المستهدفة: هاتف Android عبر Termux وARM64؛ يجب إثبات قابلية البناء فعليًا قبل اعتماد أي اعتماد أو إصدار.

## حدود هذه المرحلة
هذه المستندات تصف التصميم المقترح ولا تعني أن الميزات نُفذت أو اختُبرت. بعد مراجعة الوثائق واعتمادها، نبدأ تأسيس مشروع Android فارغ قابل للبناء، ثم نضيف الميزات تدريجيًا.

## المستودع المرجعي
المشروع السابق CinemaStream مرجع للأفكار والتجارب فقط. لا يُعد هذا المستودع فرعًا منه، ولن تُجرى عليه تعديلات ضمن إعادة البناء الحالية.
